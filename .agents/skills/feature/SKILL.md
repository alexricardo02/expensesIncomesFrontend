# Implement New Functionality

I’m going to ask you to implement a NEW FEATURE. Before writing any code:

1. Analyze the existing related code and structure in the project.
2. Apply ALL the rules in .agents/rules/style.md without exception.
3. If the feature involves persistence + logic + notifications, separate them into
   distinct classes (e.g., Service, Repository, NotificationService).
4. Strictly validate any new input.
5. Include the necessary interfaces/DTOs.
