# Debugging and Fixing Bugs

I'm going to present you with an error or unexpected behavior.

1. Clearly diagnose the root cause before touching the code.
2. Fix it by validating the edge cases that caused the failure.
3. Add robust error handling so the app doesn’t crash in that scenario.
4. Make sure the fixed exception doesn’t leak infrastructure details
   to the client.
5. Maintain SRP in the solution.
